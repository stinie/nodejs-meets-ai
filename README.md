# 🤖 Node.js Meets AI

A small Node.js project exploring how to integrate AI into a backend application using the Groq API.

Built as a code-along exercise while learning full-stack web development during my Matrix Master bootcamp.

## About the project

The goal is to understand how a Node.js application can communicate with an AI service.

I'm using this project to become more familiar with APIs and how AI can be integrated into my own applications.

## Code-along tutorial

Based on [Integrate Groq in Node.js Application | Build Your First AI App (Full Tutorial)](https://www.youtube.com/watch?v=hTUrbDPFldI) by **Learn Code With Vishwas**.

## Built with

- Node.js
- Express
- Groq SDK
- dotenv — environment variables
- Nodemon — development server

## Run locally

You'll need Node.js, npm, and a Groq API key.

Clone or download this repository, open the project folder in your terminal, and install the dependencies:

```bash
npm install
```

Create a `.env` file and add your Groq API key using the environment variable name expected by the application.

Start the development server:

```bash
npm run dev
```

Or run the application with:

```bash
npm start
```

Keep your API key private. Do not commit your `.env` file to GitHub.
